# Artwork

No images from Tencent's Honor of Kings (王者荣耀) are included here. Everything
is generated for this game or drawn in code.

- `luban-directions.webp`: an eight-direction sprite sheet of 鲁班七号,
  generated with an image model on 2026-10-14. Tencent's classic 鲁班七号 splash
  art was used only as the character reference; the character and its design
  belong to Tencent, so treat this as fan art.
- `canyon.webp`: a generated training-ground painting inspired by the
  canyon's look; it is not a map taken from the game.

Both were generated as PNG and re-encoded to WebP (about 0.7 MB instead of
5.4 MB) so the game loads quickly on phones. Prompts are in `GENERATED.md`.
Skill effects, motion, the skill seals on the start screen and the 闪现 button
are drawn in code.
